# Чікін склад — онлайн-збірка APK

## Найпростіше через GitHub
1. Створи безкоштовний акаунт на GitHub.
2. Створи новий репозиторій, наприклад `chikin-sklad`.
3. Завантаж у нього **всі файли цієї папки**.
4. Відкрий вкладку **Actions**.
5. Обери **Build APK** і натисни **Run workflow**.
6. Після завершення відкрий виконання workflow і внизу знайди **Artifacts** → `Chikin-Sklad-debug-apk`.
7. Завантаж ZIP, розпакуй його та встанови `app-debug.apk` на Android.

На телефоні може знадобитися дозволити встановлення програм із браузера/файлового менеджера.
